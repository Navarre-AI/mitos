Set up Mitos

Mitos reads your FileMaker data through the server’s OData API. It never writes to your file.

Before you start, in the FileMaker Server Admin Console:
1. Turn on OData (Connectors).
2. Use an account whose privilege set has the fmodata extended privilege in each file to search.
3. That is everything Mitos needs from the file: no layouts, no scripts, no plugin.

Last step: copy the Mitos scripts into your solution.

  1. Download the beacon script and paste it into Script Workspace. The paste needs the MBS plug-in or another clipboard tool that puts script XML on the clipboard. Without one, build the two steps by hand from the outline below.
  2. The outline of the beacon: 
    OnWindowTransaction trigger on the file, set to "Mitos Beacon"

Script "Mitos Beacon"
  Perform Script on Server [ "Mitos Beacon Post" ;
    Parameter: Get ( ScriptParameter ) ]   # the transaction JSON

Script "Mitos Beacon Post"
  Insert from URL [ /api/records/changed?key=<your site password> ;
    cURL: -X POST -H "Content-Type: application/json"
          -d @$json ]                       # the JSON from the parameter
